# Points, Pool, Deals: The Three Rummy Formats, Explained Plainly

Most new players pick a rummy format by whichever button is biggest. This page exists so you can pick by what the format actually does to your evening — all three live inside both apps catalogued on [123 Rummy Yono](https://123rummyyono.com/).

| Format | How it ends | Suits a player who… |
|---|---|---|
| Points | Every hand is settled on its own | Wants short, independent games |
| Pool | Players are eliminated as points pile up | Likes one long contest with a last survivor |
| Deals | A fixed number of deals, best score wins | Wants a known finish time |

The details behind the table — sizes, ratings and which app carries what — are kept in one place: the fuller listing is [123 Rummy, the 51 MB app](https://123rummyyono.com/123-rummy/), and the lighter one is [Rummy 123, the 34 MB app](https://123rummyyono.com/rummy-123/).

One-line summary worth memorising: **Points is a sprint, Pool is an elimination, Deals is a timetable.** Choose the evening first; the format follows.
